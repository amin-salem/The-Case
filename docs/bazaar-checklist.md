مد داستانی فعلاً متوقف است و برای بازیکن بسته می‌ماند (`STORY_SEASON.opens_at` = 2099).

## ۱. سرور (لیارا)
- [ ] `https://gaamly.ir/health` بدون VPN باز شود و نسخه سرور ۱.۲۵.۴ یا بالاتر باشد؛ وگرنه دستی از پنل لیارا دیپلوی شود.
- [ ] `BAZAAR_MODE` روی `api_secret` (با `BAZAAR_API_SECRET`) یا `oauth` (با `BAZAAR_CLIENT_ID`, `BAZAAR_CLIENT_SECRET`, `BAZAAR_REFRESH_TOKEN`) تنظیم شود. `fake` در محیط واقعی رد می‌شود.
- [ ] پیامک قاصدک: خطای ۴۱۲ حل شود یا مطمئن شوی ثبت‌نام و بازی عادی به تأیید شماره گیر نمی‌کند (تست روی گوشی تمیز).
- [ ] یک بار با کلید ادمین `POST /admin/players/purge-smoke` صدا زده شود.
- [ ] بعد از ساعت ۰۱:۳۰ شب پنجشنبه: `server/tools/load_test.py` را از داخل ایران اجرا کن و عددها را برای Claude بفرست (تصمیم درباره ارتقای پلن).

## ۲. پنل توسعه‌دهنده کافه بازار
- [ ] ساخت اپ؛ نام پکیج باید با APK یکی باشد (`ir.gammly.parvandeh` در README).
- [ ] پنج محصول درون‌برنامه‌ای با همین شناسه‌ها: `coins_small`, `coins_medium`, `coins_large`, `starter_pack`, `vip_monthly` (قیمت‌ها را خودت می‌گذاری).
- [ ] کلید RSA عمومی پنل → secret گیت‌هاب `BAZAAR_RSA_KEY` → سپس APK دوباره ساخته شود (`git push -f origin <شاخه>:release`). APK ساخته‌شده قبل از این کلید، خرید را درست تأیید نمی‌کند.
- [ ] صفحه اپ: نام، توضیح، آیکون، اسکرین‌شات، دسته‌بندی، رده سنی.
- [ ] آدرس‌ها: حریم خصوصی `https://gaamly.ir/privacy`، شرایط `https://gaamly.ir/terms`، حذف حساب `https://gaamly.ir/delete-account`. در متن حریم خصوصی و صفحه اپ: شماره موبایل فقط برای امن کردن حساب است و به‌صورت هش ذخیره می‌شود.

## ۳. فایل APK
- [ ] با کلید اصلی (`ANDROID_KEYSTORE_*`) امضا شده باشد، نه کلید دیباگ.
- [ ] شماره build در هر آپلود جدید بالاتر باشد.
- [ ] بعد از آپلود APK نهایی روی `release` پوش نکن، مگر نسخه جدید بسازی و دوباره آپلود کنی.
