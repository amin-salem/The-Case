## راستی‌آزمایی و محدودیت تحویل

فرمان محلی: `python build_audit.py` در پوشهٔ snapshot؛ JSON/CSV، تطبیق registry، سن، شمارش‌ها، هش و decode را تولید می‌کند. ۱۹۸ جایگاه با assertion کنترل شد. SHA فایل‌ها پیش از اجرا با درخت remote مقایسه شد.

تست `server/tests/test_case_art_contract.py` در main نیست؛ نسخهٔ آن و تست Flutter در شاخهٔ اصلاح قبلی پیدا شد و باید همراه سه تصویر و registration منتقل شود. در این مرحله تست سرور یا Flutter را «سبز» اعلام نمی‌کنیم: این snapshot انتخابی است، نه checkout کامل runnable. منطق یکتایی شناسه مستقل روی هر ۶۹ JSON اجرا شد و صفر تکرار داد؛ این جای اجرای pytest در CI نیست.

ساخت شاخه با GitHub connector برای `art/portrait-pool` (با SHA و base_ref) و نام جایگزین مجاز `art/portrait-pool-20261107` با HTTP 422 «Reference update failed» شکست خورد. `git ls-remote` نیز credential قابل استفاده ندارد. هیچ شاخه یا commit راه‌دور ساخته نشده؛ CI جدیدی وجود ندارد. گزارش و شواهد در بستهٔ قابل دریافت نگهداری می‌شود. شرط آغاز مرحلهٔ ۲، ثبت موفق همین مرحله روی شاخه است و هنوز برقرار نشده.
