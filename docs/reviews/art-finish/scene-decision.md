# تصمیم نسخه‌های صحنه برای امین

در این شاخه هیچ صحنه‌ای تولید یا از شاخهٔ قبلی وارد نشده و scene_variant به کد/پرونده اضافه نشده است. ۲۰ تصویر پایهٔ main حفظ شده‌اند. پیشنهاد، فقط پس‌زمینهٔ فضاساز دقیق‌تر است؛ تصویر نباید مدرک، ساعت قابل استناد یا پاسخ پرونده را نشان دهد.

برای ۷۷ پروندهٔ نوشته‌شده، پیشنهاد قبلی ۶۰ نسخهٔ تازه دارد؛ با طرح‌ها ۷۱ نسخه. ۴ کلید پایه نیز بدون نسخه نگه داشته می‌شوند. این پیشنهاد طراحی است و حداقل اثبات‌شده نیست.

دو نمونهٔ شاخهٔ قبلی ۹۵٬۶۴۲ و ۱۳۱٬۸۲۲ بایت‌اند؛ با همین بازه، ۶۰ نسخه حدود ۵٫۷۴ تا ۷٫۹۱ مگابایت و ۷۱ نسخه حدود ۶٫۷۹ تا ۹٫۳۶ مگابایت دارایی اضافه می‌کند. این افزایش تخمینی دارایی است؛ افزایش APK بدون ساخت قابل اندازه‌گیری نیست. WebP از قبل فشرده است و فشرده‌سازی ZIP نباید صرفه‌جویی بزرگ فرض شود.

تصمیم پیشنهادی: ابتدا فقط ۲ نسخهٔ برج ساعت و آپارتمان، حدود ۲۲۷٬۴۶۴ بایت، بررسی شود؛ سپس سراغ مکان‌های پرتکرار برویم. انتخاب امین بین همین ۲ مورد، ۶۰ نسخهٔ نوشته‌شده‌ها، یا حفظ فعلی لازم است. این صفحه مجوز تولید نیست.
