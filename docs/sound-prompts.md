# Sound prompts for «پرونده»

Every prompt below works in an AI sound tool (ElevenLabs Sound Effects, Stable Audio).
Each one also has **search words** for free sound libraries (Pixabay, Freesound) in case
you'd rather download than generate.

## Before you start: licence

The app sells coins and VIP, so it is a **commercial** product.
- **Free AI plans are non-commercial.** ElevenLabs' and Stable Audio's free plans don't allow
  use in a paid app. Their cheapest paid plan does (ElevenLabs Starter is about $5 for one month).
  You can subscribe for one month, make everything, then cancel.
- **Free and commercial-safe:** Pixabay Sounds (no credit needed) and Freesound files marked
  **CC0** (filter by licence: "Creative Commons 0").
- Don't use anything marked "non-commercial" or "NC".

## File rules (so I can drop them straight in)

- Name each file **exactly** as written in this document (for example `stamp.ogg`). mp3 or wav
  is fine too: I'll convert, trim and balance the volumes.
- **Short effects:** 0.2–1.5 s, start immediately (no silence at the start), mono is fine.
- **Ambience loops (`amb_*`):** 30–60 s, should loop smoothly, quiet and calm, with no voices
  speaking clear words.
- **Stings (`sting_*`):** 2–4 s, a short dramatic hit when a case opens.
- No real music copied from films. No gunshots, screams or gore.
