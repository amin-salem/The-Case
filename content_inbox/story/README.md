# صندوق ورودی فصل‌های داستان

فایل JSON هر فصلی را که ChatGPT نوشته (مثلاً `ch02.json`) این‌جا بگذار (روی شاخه‌ی `story-inbox`، نه `main`).
اجرای شبانه فقط اعتبارسنجی و ایمپورت می‌کند: فصل خوب می‌رود به `imported/`، فصل رد‌شده به `rejected/` همراه
`<نام>.اصلاحیه.txt` (پیامی که باید در ChatGPT بچسبانی). جزئیات: `docs/story-workflow.md`.
